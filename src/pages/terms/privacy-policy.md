本站是静态站点，页面本身不含服务端程序，不主动收集访客信息。以下情形除外。

## 服务器日志

站点托管于阿里云 ECS。Web 服务器按常规记录访问日志，包含 IP 地址、访问时间、请求路径与 User Agent，用于故障排查和安全审计。

## 评论与访问统计

**评论功能启用后**，本站使用 [Waline](https://waline.js.org) 承载评论。发表评论时会记录：

- 昵称、邮箱、网址（由你自行填写）
- IP 地址与 User Agent
- 评论内容及所在页面

邮箱用于在收到回复时通知你，并会经哈希处理后用于获取 Gravatar 头像。页面访问量统计同样由 Waline 记录，只保存路径与计数，不关联到具体个人。

## 第三方资源

页面会从以下第三方加载资源，它们可能因此获知你的 IP 与 User Agent：

- 字体服务 Fontshare
- 统计接口 Substats，用于展示 GitHub、Steam 等平台的公开数字

这些服务的数据处理遵循各自的隐私政策。

如需查询、更正或删除你在本站留下的数据，可通过 <me@residream.dev> 联系我。
