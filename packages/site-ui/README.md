# Shared site UI

主站与访问统计、网站状态、在线工具共用这里的主题、页头、页脚、分区布局和交互。

- 公共样式：`style.css`；公共模板：`render.ts`。
- 标题、导航、页脚链接仍在主站 `src/site.config.ts` 配置。
- `bootstrap.js` 在首次绘制前应用主题，`client.js` 处理导航和主题切换。
- 只同步外观偏好 Cookie，不包含统计、登录或业务数据。
- 主站保留完整导航和头像；三个子站的页头采用「Residream の blog / 当前应用」和主题按钮（手机上只显示当前应用名），保留页脚及各自的 Powered by。CyberChef 使用全宽工作台，其余站点沿用主站分区布局。

在主站执行 `bun run ui:sync`，将固定版本的资源同步到同级目录下的三个项目。生成文件不要手改；各应用的功能和布局适配在各自源码里维护。同步后分别检查、构建和部署，脚本不会提交代码或上线。

所有页面资源随各站一起发布，不依赖主站在线。主站的普通文章更新不需要同步；修改公共 UI 或导航、页脚后再同步。资源路径包含内容哈希，避免新旧版本混用。
